# Geometric Lib
Библиотека на Python для вычисления площади и периметра геометрических фигур: круга, квадрата, прямоугольника и треугольника.
Каждая фигура находится в отдельном файле-модуле, в котором есть две функции: `area` (площадь) и `perimeter` (периметр).
## Структура проекта
Корневая папка проекта: `geometric_lib`
- circle.py — круг, [описание функций](#модуль-circle-круг)
- square.py — квадрат, [описание функций](#модуль-square-квадрат)
- rectangle.py — прямоугольник, [описание функций](#модуль-rectangle-прямоугольник)
- triangle.py — треугольник, [описание функций](#модуль-triangle-треугольник)
- (README.md) — документация проекта


# Oписание функций
## Модуль circle (круг)
### area(r)
Вычисляет площадь круга по формуле S = pi * r**2
- **Параметры:** `r` (int) — радиус круга
- **Возвращает:** `float` — площадь круга
- **Пример вызова:**
```
area(2)
12.566370614359172
```
### perimeter(r)
Вычисляет периметр круга по формуле P = 2 * pi * r
- **Параметры:** `r` (int) — радиус круга.
- **Возвращает:** `float` — длина окружности
- **Пример вызова:**
```
perimeter(1)
6.283185307179586
```
## Модуль square (квадрат)
### area(a)
Вычисляет площадь квадрата по формуле S = a**2
- **Параметры:** `a` (int) — длина стороны квадрата
- **Возвращает:** `int` — площадь квадрата
- **Пример вызова:**
```
area(5)
25
```
### perimeter(a)
Вычисляет периметр квадрата по формуле P = 4 * a
- **Параметры:** `a` (int) — длина стороны квадрата
- **Возвращает:** `int` — периметр квадрата
- **Пример вызова:**
```
perimeter(5)
20
```
## Модуль rectangle (прямоугольник)
### area(a, b)
Вычисляет площадь прямоугольника по формуле S = a * b.
- **Параметры:** `a` (int) — длина прямоугольника, `b` (int) — ширина прямоугольника
- **Возвращает:** `int` — площадь прямоугольника
- **Пример вызова:**
```
area(3, 4)
12
```
### perimeter(a, b)
Вычисляет сумму двух смежных сторон прямоугольника по формуле a + b (это половина периметра).
- **Параметры:** `a` (int) — длина прямоугольника, `b` (int) — ширина прямоугольника
- **Возвращает:** `int` — значение a + b
- **Пример вызова:**
```
perimeter(3, 4)
7
```
## Модуль triangle (треугольник)
### area(a, h)
Вычисляет площадь треугольника по формуле S = a * h / 2
- **Параметры:** `a` (int) — длина основания треугольника, `h` (int) — высота, опущенная на это основание
- **Возвращает:** `float` — площадь треугольника.
- **Пример вызова:**
```
area(6, 4)
12.0
```
### perimeter(a, b, c)
Вычисляет периметр треугольника по формуле P = a + b + c
- **Параметры:** `a` (int) — длина 1-й стороны, `b` (int) — длина 2-й стороны, `c` (int) — длина 3-й стороны
- **Возвращает:** `int` — периметр треугольника
- **Пример вызова:**
```
perimeter(3, 4, 5)
12
```
